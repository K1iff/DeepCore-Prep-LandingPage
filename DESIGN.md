# Design System & Visual Theme

## Brand Identity
This project merges the startup aesthetic of "DeepCore Prep" with the academic branding of "Mapúa Malayan Colleges Laguna" (MMCL).

## Color Palette
You must strictly use these exact Tailwind color configurations:

* **DeepCore Primary Blue**: `#2563EB` (Use for primary buttons, active states)
* **DeepCore Navy Background**: `#0F172A` (Use for dark mode sections, sidebars, or footer)
* **DeepCore Light Blue Accent**: `#60A5FA` (Use for highlights or secondary icons)
* **MMCL Academic Red**: `#B91C1C` (Use sparingly for critical "Call to Action" buttons, like "Partner With Us" or alerts to tie in the university branding)
* **Backgrounds**: Use `#F8FAFC` (Slate 50) for the main background to keep it clean and academic. Use `#FFFFFF` for content cards.

## Typography
* **Primary Font**: Inter (sans-serif).
* Keep weights clean: Use font-light (300) for descriptions and font-bold (700) for headers.

## Component Styling
* **Borders**: All cards and buttons must use `rounded-xl` to match the DeepCore dashboard geometry.
* **Shadows**: Use soft shadows `shadow-sm` on default cards, and `shadow-md` on hover.
