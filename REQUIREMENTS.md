# Landing Page Requirements

## Tech Stack
Next.js (App Router), React, Tailwind CSS, TypeScript, Lucide React (Icons).

## Core Objective
Build a standalone landing page for "DeepCore Prep", a psychometric licensure exam platform utilizing RAG (Retrieval-Augmented Generation). 

## Page Structure
1. **Navigation Bar**: Logo placeholder on the left. Links on the right (Features, Tech, Contact). A prominent "Partner With Us" button using the MMCL Academic Red color.
2. **Hero Section**: Strong headline about AI licensure prep. Subheadline about RAG questionnaire generation. Two buttons: "Try Beta" and "Request Demo".
3. **Features Grid**: Three distinct cards highlighting:
   * Scheduled Mock Exams & Weekly Activity tracking.
   * Interactive Progress Roadmap & Diagnostic Baseline.
   * Cohort Workspace Management for review centers.
4. **How It Works (Tech Section)**: A 3-step visual layout explaining RAG architecture, vector ingestion, and exam generation using Supabase.
5. **Academic Roots**: A section acknowledging development by students from the College of Computer and Information Science at Mapúa Malayan Colleges Laguna.
6. **Footer**: Contact details, copyright, and simple navigation links.
